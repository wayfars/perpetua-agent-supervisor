# Applied AI and inference operations portfolio

These projects connect application behavior to model evaluation, serving measurements, and agent operations.

| Project | Engineering evidence |
| --- | --- |
| [Notebook](https://github.com/wayfars/notebook-ai-demo) | Source-grounded chat, inspectable excerpts, retrieval baselines, and separate live-answer checks |
| [AI Task Evaluations](https://github.com/wayfars/ai-task-evals) | Explicit task contracts, strict structured grading, failure accounting, and evaluation methodology |
| [Local Inference Bench](https://github.com/wayfars/local-inference-bench) | Streaming latency, concurrent request outcomes, accepted work, and safe reproducibility manifests |
| [Perpetua](https://github.com/wayfars/perpetua-agent-supervisor) | Durable agent handoffs, interrupted-process reconciliation, bounded recovery, and human escalation |

The repositories use fictional fixtures and fresh public histories. They contain no original user databases, session transcripts, credentials, employer/client data, or private deployment settings. Public release preparation included secret scanning and a separate content/asset review. Generated results still need review before sharing.

Implementation was assisted by AI coding agents. The code, tests, grading contracts, measured outcomes, and limitations are published so the engineering claims can be inspected. Local tests, mock adapters, live connectivity checks, and controlled model comparisons are distinct kinds of evidence; none should be substituted for another.

The current releases are focused engineering demonstrations. Notebook's authored corpus does not establish general retrieval quality or injection resistance; microtask scores are not broad model rankings; client timing is not GPU occupancy; process supervision is not a security sandbox.
